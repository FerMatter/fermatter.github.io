Math rendering engine

FerMatter requires LaTeX or Typst to render equations and drawings. The commands below are for macOS.

LaTeX

Full TeX Live

brew install --cask mactex-no-gui
brew install pdf2svg poppler ghostscript

BasicTeX

brew install --cask basictex
brew install pdf2svg poppler ghostscript
sudo /Library/TeX/texbin/tlmgr update --self
sudo /Library/TeX/texbin/tlmgr install latexmk preview pdfcrop pgf mathtools

For Ubuntu (experimental)

Ubuntu 24.04 · amd64. Limited testing; use file export for images. Native image clipboard and recoverable project deletion are unavailable.

First-time APT setup
sudo apt update
sudo apt install curl
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://fermatter.github.io/apt/fermatter.gpg | sudo tee /etc/apt/keyrings/fermatter.gpg > /dev/null
curl -fsSL https://fermatter.github.io/apt/fermatter.sources | sudo tee /etc/apt/sources.list.d/fermatter.sources > /dev/null
sudo apt update
sudo apt install fermatter

Install LaTeX or Typst separately:

LaTeX tools for Ubuntu
sudo apt install latexmk texlive-latex-extra texlive-extra-utils texlive-pictures ghostscript pdf2svg poppler-utils lmodern cm-super-minimal

For Typst, follow the official installation instructions.

Update

sudo apt update
sudo apt install --only-upgrade fermatter
