Use FerMatter

  • Start with paper to slides: choose an equation, copy it, and paste it into your presentation.
  • Development prototype for Apple Silicon Mac; requirements.

First launch

  • Choose a project folder, then Next. Review Compiler tools and select Finish Setup. This setup runs once; existing completed setups are retained.
  • Detected executable paths appear automatically. Enter a full path or use the folder button to choose another executable. Missing tools can be installed later; only the tools for your project format are needed.
  • New projects, ZIP imports, dropped folders, and duplicates use this location. Change it later in Settings → Projects.
  • Four editable demos are added under Demos: LaTeX, Typst, TikZ, and CeTZ. An existing Demos folder is kept; a numbered folder is used instead.
  • Recognized, unchanged sample sources move to their new copies in Projects, retaining Library edits, Source drafts, and Instant history. Original files and modified projects stay intact.

Make your first slide

  1. Bring an equation from your paper.
  2. Make a version for your talk.
  3. Choose the export size and format.

Other tasks

  • Make an equation instantly, without creating a project.
  • Switch between Grid view and List view on Projects; the app remembers your choice. Each project shows its folder path below its name; hover to read a long path in full.
  • Start from pasted equations.
  • Find an equation in the paper PDF.
  • Edit the project source.
  • Use TikZ or CeTZ drawings.
  • Change shortcuts and appearance.
  • Search, render and export through MCP or CLI.
  • Understand extraction limits.
  • Why FerMatter.

Try a sample

  • Open one of the demos added during setup. Compiling requires the tools for its format.
  • Additional copies: download LaTeX, Typst, TikZ, or CeTZ, then choose Open file or ZIP.
  • All samples use synthetic material.
