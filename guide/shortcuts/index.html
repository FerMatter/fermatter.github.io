Shortcuts

Settings → Shortcuts (⌘,): click an assignment to record a new one. Duplicate and reserved shortcuts are rejected.

ActionDefault
Copy / Export image⇧⌘C / ⇧⌘S
Library / Source⌘E / ⌥⌘E
Toggle PDF⌥⌘P
Format source⇧⌥F

Window zoom

⌘+ / ⌘− / ⌘0 zoom or reset the interface. PDF uses ⌃⌘+ / ⌃⌘− / ⌃⌘0 (Fit).

Zoom one pane

Control + scroll over Projects, Library or PDF. Display zoom leaves export sizes unchanged.

Manage shortcuts and themes as files

Edit JSON / Reload / Import… / Export… manages keybindings.json. Invalid files keep the last valid settings.
